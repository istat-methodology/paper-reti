# Archivio

Materiale superato, conservato per riferimento. Non si usa e non è mantenuto: gli script possono non girare più dopo lo spostamento.

- `pipeline_v1/`: pipeline LLM originale (estrazione e spezzatura del JSON unico). Il suo prompt è in `prompts/v1/`.
- `annotazione_v1/`: fogli di annotazione della prima versione (con la Toscana).
- `annotazione_campione_v1/`: script che hanno estratto il primo campione (36 protocolli) e preparato i fogli di annotazione. I dati (campione e fogli) sono in `annotazione/gold_v1_legacy/`.
