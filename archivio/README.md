# Archivio

Materiale superato, conservato per riferimento. Non si usa e non è mantenuto: gli script possono non girare più dopo lo spostamento.

- `pipeline_v1/`: pipeline LLM originale (estrazione e spezzatura del JSON unico). Il suo prompt è in `prompts/v1/`.
- `annotazione_v1/`: fogli di annotazione della prima versione (con la Toscana).
- `annotazione_campione_v1/`: campione di 36 protocolli (Toscana in tutto, più 25 altri), script che l'ha estratto e fogli di annotazione v2 pre-compilati con l'output della pipeline v1. Superato il 2026-10-31: l'assunzione della Toscana come set di sviluppo, inclusa per intero, era arbitraria per un paper. Se Paolo ed Elena restituiscono fogli compilati su questo campione, tenerli qui.
